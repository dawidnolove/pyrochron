PURPOSE AND SCOPE
Pyrochron is a runnable local Streamlit web app (app.py / launch.ps1) with a local JSON/CSV API (api.py). It produces a historical monthly NASA FIRMS active-fire detection calendar and Harmonized Fire Activity Index (HFAI) across four study rectangles, plus an optional approximate daily 1 km VIIRS cluster view for inspecting repeat detections. Its defined purpose is retrospective comparison of seasonal detection activity and transparent MODIS/VIIRS aggregate-count alignment. Neither view is an estimate of burned area, unique-fire incidents, or individual fire causes. See outputs/reports/measurement-scope.md for the question, data contract, and validation evidence; outputs/reports/data-integrity-audit.md for raw-file checks.

https://power.larc.nasa.gov/docs/methodology/meteorology/
NASA POWER homepage:
https://power.larc.nasa.gov/
Point API endpoint:
https://power.larc.nasa.gov/api/temporal/monthly/point

Parameters: T2M temperature (degrees Celsius) and PRECTOTCORR precipitation (mm/day); community AG; monthly values are converted to monthly precipitation totals using days per month. NASA POWER monthly point values are gridded MERRA-2 context at area centroids, not measurements at individual fire pixels and not inputs to the HFAI calibration. The four preserved JSON responses contain 312 monthly-API keys per parameter: 288 calendar months from 2001-01 through 2024-12 plus 24 annual aggregate month-13 values. Ingestion uses only the 288 calendar-month entries and excludes month 13.

5. RELATED DATA CATALOGS AND PUBLISHED CONTEXT (NOT INPUTS TO THIS INDEX)

The following sources describe separate research questions; the current project's monthly detection-activity index is reproducible from the preserved FIRMS and POWER inputs above. No downloads from these catalogs are required to build or assess that index.

Cloud and observation-opportunity products (for a future study of detections conditional on valid, clear satellite viewing):
MODIS Terra/Aqua MOD35_L2 / MYD35_L2 cloud mask product description (cloud confidence and shadow flags; swath Level 2): https://modis.gsfc.nasa.gov/data/dataprod/mod35.php
NASA LAADS transition catalogue for corresponding MODIS/VIIRS cloud-mask products: https://ladsweb.modaps.eosdis.nasa.gov/learn/modis-to-viirs-transition
Candidate daily VIIRS fire-mask context: VNP14A1 (S-NPP), VJ114A1 (NOAA-20), VJ214A1 (NOAA-21). Product file specification: https://ladsweb.modaps.eosdis.nasa.gov/filespec/VIIRS/1/VNP14A1
NASA Earthdata Login data-access guide (LAADS archive downloads use a locally configured Earthdata token): https://urs.earthdata.nasa.gov/documentation/for_users/data_access
NASA active-fire point rows alone do not provide a view-time denominator. A future cloud-conditioned study would need platform-matched geolocation, valid swath/orbit coverage, acquisition time, and quality flags; cloud fraction alone is not an observation denominator. That is a distinct estimand from the current index.
Metadata-only LAADS granule searches were exploratory research only; no cloud-mask granules are inputs to this release. Product versions and specifications should be rechecked against the linked LAADS catalog before any future cloud-conditioned analysis.

NASA POWER also distributes daily cloud amount from the CERES SYN1deg product. This is gridded meteorological/radiative context derived from combined CERES, MODIS cloud retrievals, and geostationary-imager sampling; it is not a sensor-specific cloud mask at a FIRMS overpass. Documentation: https://power.larc.nasa.gov/docs/methodology/data/sources_clds_aerosols/. The unreferenced `inputs/climate/nasa_power_cloud_daily_2024.json` is not used by the current pipeline or interpreted as overpass cloud.

Land-cover and independent event-label sources (for future work on setting or cause):
NASA MODIS MCD12Q1 yearly global 500 m land-cover product and quality fields: https://ladsweb.modaps.eosdis.nasa.gov/missions-and-measurements/products/MCD12Q1/
Land cover describes surface context and does not establish ignition cause. Cause attribution would additionally require independent event labels and validation; the current index makes no per-hotspot cause assignment.

Google Earth Engine Community Catalog, FIRMS historical vector collections. Reference for archive coverage/schema only; not an input to this project:
https://gee-community-catalog.org/projects/firms_vector/

Vadrevu et al., Punjab MODIS/VIIRS active-fire and emissions comparison, published context only; not a Pyrochron result or ingested dataset:
https://pmc.ncbi.nlm.nih.gov/articles/PMC6108185/

Giglio et al. (2006), Global estimation of burned area using MODIS active fire observations. This is a separate calibrated burned-area methodology and is not applied to Pyrochron HFAI:
https://acp.copernicus.org/articles/6/957/2006/

Wooster et al. (2005), FRP derivation and calibration relationships between biomass consumption and fire radiative power. Experimental calibration context; not a conversion applied to this project:
https://doi.org/10.1029/2005JD006318

No non-NASA dataset is ingested in the analysis. The catalog and papers above are references only.
